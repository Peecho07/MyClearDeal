# MyClearDeal hashtag bank (sized sets, 3-5 per post)

Tiers are estimates from tag specificity. **Check each tag's post count in Instagram search before the first use** and
move it to the right tier (niche under 50k, mid 50k-500k, broad 500k+). Put the set in the first comment.
Rotate the niche tags; never paste the same block on every post.
